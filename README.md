# Day 16: Dataset Exploration Using Pandas

## 📌 Description

This project focuses on exploring a student dataset using Pandas in Python. I created a dataset containing student names, ages, marks, and cities, then used different Pandas functions to understand its structure and statistics.

## 🎯 Objective

To learn how to explore a dataset and understand its basic information using Pandas.

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook

## 📊 Dataset Details

The dataset contains information about 5 students with the following columns:

* Name
* Age
* Marks
* City

## 💻 Functions Used

* `pd.DataFrame()` – Creates a table from data.
* `df.shape` – Displays the number of rows and columns.
* `df.columns` – Displays column names.
* `df.info()` – Provides information about columns and data types.
* `df.describe()` – Generates a statistical summary of numerical columns.
* `df.head()` – Displays the first 5 rows.
* `df.tail()` – Displays the last 5 rows.

## 🔍 Key Observations

1. The dataset contains 5 students and 4 columns.
2. The average student mark is 82.
3. Priya scored the highest mark of 92.
4. Rahul scored the lowest mark of 67.
5. All five students have complete data with no missing values.

Through this task, I learned how to explore datasets using Pandas, check their structure, understand data types, and summarize numerical information.
